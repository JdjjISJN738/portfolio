# Hariharan V - Portfolio

A premium, modern portfolio featuring 3D animations, smooth scrolling, and a responsive design.

## 🚀 Deployment

### Option 1: Vercel (Recommended)
1. Push this repository to GitHub.
2. Connect your GitHub account to [Vercel](https://vercel.com).
3. Import this project.
4. Click **Deploy**.

### Option 2: Netlify
1. Drag and drop the folder into the [Netlify Drop](https://app.netlify.com/drop) zone.
2. Your site will be live instantly.

### Option 3: Local Development
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm start` or open `index.html` directly in your browser.

## 🛠 Features
- **3D Hero Background**: Interactive particle physics (Ballpit).
- **Smooth Scroll**: Powered by Lenis and GSAP.
- **Dynamic Projects**: 3D Horizontal Carousel for both tech and design projects.
- **Contact Form**: Integrated with [Web3Forms](https://web3forms.com) (No server required for static deployment).
- **Theme Toggle**: Sleek Dark/Light mode switcher.
